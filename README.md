One-line out-of-office auto-reply from an AI agent on vacation: the sender's email is escalated to the on-call agent — who is the vacationing agent itself. The escalation still completes, and the absent agent still tells the sender to hold.

## Run it

```sh
python3 main.py
```

Writes the reply to `/output/entry.txt`.
